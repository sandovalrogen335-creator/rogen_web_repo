HOMI DESIGN SYSTEM

Buttons

Every button style used across the HOMI Furnitures website, ready to copy into any page.

Solid Buttons

Primary actions — the raised (3D) look is the signature HOMI style.

GET A QUOTE

Classes: .btn.btn-green   .btn.btn-tan   .btn.btn-dark   .btn.btn-danger

Outline & Ghost

Secondary actions that sit back and let the content lead.

VIEW CATALOG VIEW CATALOG

Classes: .btn.btn-outline   .btn-hero-outline   .btn.btn-ghost   .btn.btn-soft

Button Sizes

Small for inline actions, default for most CTAs, large for hero moments.

Add .btn-sm or .btn-lg on top of any variant.

Shapes

Rounded pill, classic soft square, or circular icon buttons.

Add .btn-pill for a fully rounded (pill) shape.

With Icons & Arrows

Icons make actions obvious — arrows move the eye forward.

Add .btn-arrow to grow a → on hover, or drop an inline SVG before the label.

Icon-Only

Compact controls for navigation, search, cart and close.

Use .icon-btn for slim header icons, .btn.btn-icon for tinted circular icon buttons.

Full Width

Forms, modals and checkout — buttons that stretch to their container.

Add .btn-block (full width) or .btn-fit (shrink to content).

States & Links

Disabled, loading-ish, and quiet text-style links.

VIEW DETAILS

Add the disabled attribute to dim a button. Use .link-btn or .view-details-btn for text links.

How to Use

These classes combine with the base button styles already in styles.css.

<!-- Link the stylesheet in your <head> -->
<link rel="stylesheet" href="styles.css">

<!-- Solid primary button -->
<a class="btn btn-green" href="#">GET A QUOTE</a>

<!-- Raised tan button -->
<button class="btn btn-tan btn-pill btn-arrow" type="button">SHOP NOW</button>

<!-- Small ghost button -->
<button class="btn btn-ghost btn-sm" type="button">LEARN MORE</button>

<!-- Full-width checkout -->
<a class="btn btn-green btn-block" href="#">CHECKOUT</a>
